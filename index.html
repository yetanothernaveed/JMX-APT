JMX APT Repository

Packages for the JMX remote CLI and daemon (jmx, jmxd, jmxcleanerd) on Ubuntu-based distributions. This repository is generated automatically from the private JMX source repository.

Install

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL __APT_PAGES_URL__/KEY.gpg | sudo gpg --dearmor --yes -o /etc/apt/keyrings/jmx.gpg
echo "deb [signed-by=/etc/apt/keyrings/jmx.gpg] __APT_PAGES_URL__ stable main" | sudo tee /etc/apt/sources.list.d/jmx.list
sudo apt update
sudo apt install jmxremote

Update

sudo apt update
sudo apt upgrade

Or upgrade only JMX:

sudo apt update
sudo apt install --only-upgrade jmxremote

Verify the repository key

curl -fsSL __APT_PAGES_URL__/KEY.gpg | gpg --show-keys

Rollback

Older package versions remain in the repository pool:

sudo apt install jmxremote=<version> --allow-downgrades

Notes

  • The repository is signed with the JMX APT signing key.
  • The package currently supports amd64 only.
  • Do not run unattended JMX upgrades during an active exam session.
